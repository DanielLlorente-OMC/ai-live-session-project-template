# Guía de formación

Abre index.html en un navegador. Incluye diez pasos, prompt de arranque y cinco ejercicios integrados para copiar. No necesita instalación, conexión a servicios ni compilación. Los enlaces a GitHub y Figma requieren internet. El progreso es local al navegador.

Documentación fuente: ../../00-arranque-centro-de-control.md y ../../05-design/ejercicios/. Si cambian los prompts, actualizar también las copias integradas en index.html.

Incluido en el repositorio del taller.
