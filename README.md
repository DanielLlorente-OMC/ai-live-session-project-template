# AI Live Session · Plantilla de proyecto

Plantilla reutilizable para organizar proyectos y practicar un flujo con GitHub, una home HTML y Figma. Incluye cinco ejercicios con contenido ficticio. Conserva las carpetas del patrón de proyecto y añade artefacto/ para las aplicaciones.

## Empezar

1. Crea una cuenta gratuita GitHub con correo OMC y usuario NombreApellido-OMC; verifica el correo.
2. Usa **Use this template → Create a new repository** para crear tu copia. Elige su visibilidad conscientemente; no incluyas datos internos en repositorios públicos.
3. Crea o abre una carpeta local y un chat llamado Centro de Control con acceso a esa carpeta.
4. Copia el [prompt de arranque](00-arranque-centro-de-control.md), sustituye nombre y URL por los de tu proyecto y pide clonar tu copia.
5. Elige uno de los [cinco ejercicios](05-design/ejercicios/README.md).

## Estructura

- 00-context/: contexto y estado.
- 01-decisions/: decisiones.
- 02-meetings/: reuniones.
- 03-research/: investigación y referencias.
- 04-information-architecture/: arquitectura y contenido.
- 05-design/: diseño y cinco ejercicios.
- 06-roadmap-and-delivery/: planificación y seguimiento.
- 07-deliverables/: entregables revisados.
- 08-links/: enlaces del proyecto.
- artefacto/: implementación HTML, estilos, recursos y documentación de cada ejercicio.

## Recorrido del taller

Preparar copia local → elegir ejercicio → construir home → revisar → commit y push → dos cambios → Figma editable y fundamentos → cambio en Figma → HTML actualizado → nueva versión.

Repositorio: archivos e historial. Clonar: descargar una copia con historial. Commit: guardar una versión local. Push: subir versiones. Pull: traer cambios. Clonar el original no concede permisos de escritura.

## Herramientas

Se necesita un agente con acceso a archivos y ejecución para clonar, instalar skills y comprobar el HTML; un chat de texto por sí solo no garantiza esas capacidades. El prompt comprueba el entorno. Playwright CLI ayuda a revisar el navegador e Interface Design aporta guía de interfaz. Figma requiere conexión y permiso de edición independientes.
